# msc-privacy

1. 数据收集： 本游戏不收集、不存储、不共享任何用户的个人身份信息（如姓名、邮箱、IP地址等）。本游戏没有集成任何第三方广告或分析SDK。

2. 本地联机功能： 本游戏支持局域网（LAN）本地联机。在联机过程中，游戏仅在本地局域网内传输必要的游戏同步数据（如玩家位置、操作指令）。这些数据不会通过互联网上传至我们的服务器，仅用于保证游戏正常运行。

3. 第三方链接： 游戏内包含跳转至 YouTube 频道的按钮，点击后将打开外部浏览器。YouTube 的隐私政策由其平台独立管理，请参考 YouTube 官方说明。

4. 联系方式： 如果您对本隐私政策有任何疑问，请联系：jiasas888@outlook.com。
